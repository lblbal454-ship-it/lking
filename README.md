# Lking Production

منصة فيديوهات قصيرة + بث مباشر + مجتمع صناع محتوى.

## المزايا
- تسجيل ودخول عبر Supabase Auth.
- ملفات شخصية لصناع المحتوى.
- رفع فيديوهات إلى Supabase Storage.
- منشورات فيديو مرتبطة بقاعدة البيانات.
- إعجاب، متابعة، وتعليقات.
- صفحة اكتشاف للمحتوى.
- غرف بث مباشر مع حالة LIVE وتحديثات Realtime.
- Creator Studio وإحصاءات أولية.
- تحديات للمبدعين وأكواد إحالة.

## تشغيل
1. أنشئ مشروع Supabase.
2. نفّذ `supabase/production.sql`.
3. أنشئ Storage bucket باسم `videos`.
4. انسخ `.env.example` إلى `.env` وضع بيانات Supabase.
5. نفّذ `npm install` ثم `npm run dev`.

## البث واسع النطاق
WebRTC المباشر داخل المتصفح مناسب للبداية والاختبار. للإطلاق الجماهيري نحتاج SFU مثل LiveKit أو خدمة بث مدارة، مع TURN وmoderation وrate limiting.

## تحقيق الدخل
الأساس جاهز لبرنامج صناع المحتوى، الهدايا، الاشتراكات والإعلانات بعد إضافة مكافحة الاحتيال ومتطلبات الدفع والامتثال.
